route-studio

把一条 GPX 变成能看清地形、看清路的线路图：三维飞越视图 + 赛段剖面 + 路书总览。 渲染目标是环法转播里那种 flyover。

进化天路

杭州萧山 · 环线 111.24 km · 累计爬升 2174 m · 13 处入级爬坡
打开三维地形 + 赛段剖面 →
路书总览（时刻表 / 爬坡 / 无补给空档） 源码

需要什么

三维视图要 WebGL2，手机上（尤其微信内置浏览器）可能不支持， 会显示提示并给一个链接跳到路书页。路书页是 2D canvas，没有这个要求。 首次打开要载入 6 MB（地形栅格 2.5 MB + 卫星影像 3.3 MB）。

自己跑一条

git clone https://github.com/wangyiyun-hub/route-studio
cd route-studio
pip3 install --user Pillow numpy

./route-studio new myroute ~/Downloads/xxx.gpx
$EDITOR routes/myroute/route.toml   # 唯一手工编辑的文件
./route-studio all myroute          # 抓 DEM + 影像，推导剖面，规划，构建
./route-studio serve myroute

route.toml 只放测不出来的东西：标题、爬坡分级阈值、渲染参数， 以及补给点（哪儿算补给、靠不靠得住、停多久）。其余一律计算 —— 坐标、海拔、剖面、分段、无补给空档、时刻表。

数据与口径

  • 高程：AWS terrain-tiles（terrarium 编码的 SRTM 30 m），z13 ≈ 16.5 m/px
  • 影像：Esri World Imagery，z16 ≈ 2.07 m/px，WGS-84 与 GPX 同基准
  • 爬坡分级是本地重标定的，非 ASO 原口径 —— ASO 的 HC 门槛是 单段爬升 1000 m，这条线最大单段 363 m，套原口径会把 14 段全压进「3 级及以下」。 页面上附了换算说明。
  • 累计爬升是方法相关量，页面标了口径（DEM 栅格 80 m 步长逐点累加）。
路线数据来自 iGPSPORT 路书，原始 <ele> 全为 0， 所有高程来自 DEM。地形的几何精度上限就是 SRTM 的 30 m； 「逼真」主要来自卫星影像，不是来自高程。
